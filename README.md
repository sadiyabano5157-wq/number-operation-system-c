# Number Operation System in C

This is a simple C program that performs different number operations using switch case and if-else conditions.

## Features
- Check Even or Odd
- Check Positive or Negative
- Check Divisible by 5
- Exit Option

## Concepts Used
- Switch Case
- If-Else
- Modulus Operator
- User Input

## Language
C Programming
